1. **CONFIRMÉ** — la redirection doi.org → arxiv est suivie et l'identité finale est enregistrée
   (`final_url`), ce qui permet de ne pas attribuer le contenu à l'URL de départ.
2. **CONFIRMÉ (danger)** — sur un site SPA, `HTTP 200 + CONTENT_OBTAINED` peut désigner une page
   inexistante. La vérification de contenu doit rester une étape distincte du code HTTP
   (cf. `L-P1-01`, désormais `EN COURS` et non close).
3. **NOUVELLE LACUNE `L-P1-12`** — la liste `redirects` du JSON est **vide** alors que
